# Day 01 – Basic MySQL Practice 

Today I started my MySQL daily practice journey.  
The focus of Day 01 was to understand **basic database operations** and write my first SQL queries confidently.


## What I learned today

### MySQL Basics
- What is a **database**
- Difference between **database** and **table**
- How MySQL stores data in tabular format


### Database Operations
- Creating a database using `CREATE DATABASE`
- Selecting a database using `USE`
- Viewing all databases using `SHOW DATABASES`


### Table Operations
- Creating tables using `CREATE TABLE`
- Understanding columns and data types
- Viewing table structure using `DESC`
- Viewing all tables using `SHOW TABLES`


### Basic SQL Queries Practiced
- `INSERT INTO` → inserting data into table
- `SELECT * FROM table_name` → fetching all data
- `SELECT column_name FROM table_name`
- Using `WHERE` condition
- Using `LIMIT`


## Practice Summary

- Created a sample database
- Created a table with multiple columns
- Inserted records into the table
- Retrieved data using basic SELECT queries
- Viewed query output in MySQL
